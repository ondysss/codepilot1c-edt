# 05-01 Plan — Release Install and Live EDT Closure Smoke

## Status

planned

## Goal

Close v0.1.9 only after the fixed plugin is packaged, installed into EDT, and verified on the real `/Volumes/T9/workspace/do` workspace.

## Depends on

Phase 4 — Live EDT Audit Remediation

## Scope

1. Build the deliverable update site from repository root:
   `mvn -DskipTests package`
2. Verify update-site artifacts under:
   `repositories/com.codepilot1c.update/target/repository`
3. Install/update the plugin in EDT from that repository.
4. Remove or ignore stale broken local p2 zip sites before checking update results.
5. Run the live audit prompt from:
   `.planning/audits/edt-extension-migration-live-audit-agent-prompt.md`
6. Inspect fresh EDT logs after the smoke.
7. Save final report under `.planning/audits/`.

## Acceptance Criteria

- Installed plugin version/qualifier matches the latest built update-site artifacts.
- `migrate_to_extension_native` dry-run succeeds and emits representative operations.
- Unsafe apply remains gated.
- `create_metadata` / `update_metadata` TypeDescription scenarios pass or fail only with expected deterministic diagnostics.
- StandardCommandGroup create/update scenarios pass.
- CommonCommand `CommandModule.bsl` path and BSL context pass.
- `mutate_role_rights` is checked with the correct validation operation.
- `get_diagnostics` is clean for extension-relevant diagnostics, or unrelated diagnostics are explicitly classified.
- Final verdict is `PASS` or `PASS_WITH_WARNINGS`; `FAIL` keeps the milestone open.

## Verification Artifacts

Save:

- build command and result,
- produced update-site plugin names/qualifiers,
- EDT install/update evidence,
- live smoke transcript or audit report,
- fresh log findings with line references.
