# Снятие проекта с рабочей области

`workspace_remove_project` снимает регистрацию одного проекта через Eclipse Resource API.
Исходники сохраняются: инструмент всегда вызывает `IProject.delete(false, false, monitor)`.
Удаление содержимого каталога и удаление расширения из информационной базы не поддерживаются.

Сначала вызовите инструмент с точным `project_name` и `dry_run: true` (это значение по умолчанию).
Проверьте `location`, `canRemove` и `blockers`. Для выполнения передайте `dry_run: false`
и `expected_location`, равный пути из предварительной проверки.

Инструмент отказывает, если на проект ссылаются другие проекты, он является базой
зарегистрированного расширения, содержит несохранённые редакторы либо недоступен `.project`.
Перед записью состояние проверяется повторно под правилом планирования рабочей области.
Ответ `removed` возвращается после проверки отсутствия регистрации и сохранности `.project`.
Повторный вызов для уже снятого проекта возвращает `not_found` без изменений.

Чтобы вернуть проект в рабочую область, вызовите `workspace_import_project` с сохранённым `location`.
