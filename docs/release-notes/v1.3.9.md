# CodePilot1C 1.3.9

## Cyrillic call graph correctness on EDT JDK 25

- BSL call parsing no longer relies on a leading regex word boundary, whose Cyrillic behavior
  differs in EDT's Axiom JDK 25 runtime.
- `edt_get_project_call_graph` and `edt_get_method_call_hierarchy` now include direct calls to
  Russian method names, while retaining file-path-qualified method identity.
- The Unicode-safe call matcher uses an explicit negative lookbehind for identifier characters;
  method-name suffixes cannot be matched from inside a longer identifier.
- Regression coverage verifies the live-shaped `HealthGETЗапрос` call to
  `ДиагностикаАртели` at line 9.

## Filesystem containment hardening

- GSD lock, state, backup, quarantine, and Markdown projection mutations now bind the project and
  target-directory identities before use and reject changed or escaped ancestry at mutation
  boundaries.
- Ship-scoped `write_file` publication uses the same guarded atomic-write path while retaining
  Eclipse workspace refresh and BM synchronization.
- Filesystem mutation now requires Java 17 `SecureDirectoryStream` and publishes only relative to
  validated, open directory handles. Providers without that primitive (including the macOS JDK 17
  default provider) fail closed before the first lock, temp, rename, cleanup, or publication.
- Read-only GSD inspection remains available on macOS and Linux through a JNA-core 5.13.0 libc
  primitive. `loadReadOnly()` performs no lock, migration, recovery, projection, or pathname
  mutation: it retains an `open`/`openat` descriptor chain with no symlink following, reads no more
  than 16 MiB from the final fd itself, and validates native `fstat` `dev`/`ino`/mode/size/link count
  before and after reading. The final file requires `nlink == 1` before reading; post-read fd
  `nlink == 0` is accepted only as a possible concurrent unlink/atomic replace state, after which
  current-path identity validation deliberately fails closed. `nlink > 1` is always rejected.
- macOS descriptor identity uses only native `fstat`, never Java attributes or `isSameFile` on
  `/dev/fd`. Linux also corroborates the still-open descriptor through `/proc/self/fd` file keys and
  `Files.isSameFile`. The native path is used even where `SecureDirectoryStream` exists because that
  Java API does not expose the fd needed for `fstat` and link-count enforcement.
- Windows, other operating systems/architectures, missing optional JNA/libc primitives, and missing
  stable file identity are unsupported and fail closed. There is no pathname-only read fallback.
  Deterministic real-path tests reject outside hard links, restored ancestor/final swaps (including
  identical size and millisecond mtime), symlinks, null/transitioning identity, corrupt/oversized
  input, and verify descriptor cleanup and zero mutation.
- Java 17 has no portable secure relative directory-creation primitive. On a provider that does
  expose `SecureDirectoryStream`, GSD and ship parent directories must already exist and the error
  names the exact directory to pre-create. On a provider without it, capability failure is reported
  first: pre-creation is not suggested because it cannot enable mutation.
- GSD tool failures caused by this provider limitation, plus GSD Ship `write_file`, return the
  provider-neutral machine-readable `error_code=unsupported` instead of generic `io`.
- Workspace-bound project identity is carried through ship publication, preventing a project-root
  swap after the initial workspace containment check from binding an escaped replacement.
- Deterministic hook-based tests cover project/directory binding, lock open, temp creation,
  publication, cleanup, quarantine rename, and missing-parent/bootstrap boundaries. Linux tests
  exercise real secure handles; forced and native non-secure-provider tests assert byte-for-byte
  unchanged trees and fail-closed behavior.

## Local acceptance evidence

CI remains disabled by repository policy. Acceptance was run locally with Java 17, the pinned EDT
`2025.1.5+34`, Maven `package`, and explicit executed/skipped counts.

macOS focused contracts and native anchored-read suite:

```bash
EDT_HOME="${EDT_HOME:?set EDT_HOME to the pinned 1C:EDT Eclipse directory}"
mvn -Dedt.home="$EDT_HOME" \
  -pl bundles/com.codepilot1c.core.tests -am \
  -Dtest=AnchoredUnixReadTest,ThrowableCauseTraversalTest,GsdStateStoreTest,GsdWorkflowServiceTest,GsdToolsTest,WorkspacePathContainmentTest \
  -Dsurefire.failIfNoSpecifiedTests=false package
```

Result: 189 discovered, 111 executed, 78 capability-skipped, 0 failures, 0 errors. Registration,
schemas, metadata, descriptions, strict integer parsing, required-criterion validation, native
populated `gsd_get_state`, shipment sanitization/idempotency, hard-link/restored-swap confinement,
all seven actual mutating GSD tool envelopes, and actual ship `write_file` executed. Mutation
lifecycle and real wrong-phase envelopes
are among the explicitly capability-skipped cases and are exercised by the Linux run below.

Linux Docker real-`SecureDirectoryStream` filesystem/GSD/shipment suite (the local Maven 3.9.16
distribution is copied into a disposable Docker volume because the cached image contains Java 17
but not Maven):

```bash
REPO_ROOT="$(git rev-parse --show-toplevel)"
MAVEN_HOME="${MAVEN_HOME:-$(mvn -v | sed -n 's/^Maven home: //p')}"
M2_REPO="${M2_REPO:-$HOME/.m2/repository}"
EDT_HOME="${EDT_HOME:?set EDT_HOME to the pinned 1C:EDT Eclipse directory}"
MAVEN_VOLUME="codepilot-gsd-maven-$$"
docker volume create "$MAVEN_VOLUME"
trap 'docker volume rm -f "$MAVEN_VOLUME" >/dev/null' EXIT
tar -C "$MAVEN_HOME" -cf - . | \
  docker run --rm -i -v "$MAVEN_VOLUME:/opt/maven" \
  eclipse-temurin:17-jdk tar -C /opt/maven -xf -
docker run --rm --user "$(id -u):$(id -g)" \
  -v "$REPO_ROOT:$REPO_ROOT" -v "$M2_REPO:$M2_REPO" -v "$EDT_HOME:$EDT_HOME:ro" \
  -v "$MAVEN_VOLUME:/opt/maven:ro" -w "$REPO_ROOT" \
  eclipse-temurin:17-jdk /opt/maven/bin/mvn \
  -Dmaven.repo.local="$M2_REPO" -Dedt.home="$EDT_HOME" \
  -pl bundles/com.codepilot1c.core.tests -am \
  -Dtest=AnchoredUnixReadTest,ThrowableCauseTraversalTest,SecureDirectoryMutationTest,GsdContentSecurityTest,GsdCoreV2Test,GsdStateStoreTest,GsdVerificationGuardTest,GsdWorkflowServiceTest,GsdToolsTest,EditFileToolEditModeTest,EditResultGuardTest,GlobToolTruncationTest,GrepToolTruncationTest,ListFilesToolTruncationTest,ReadFileToolTruncationTest,StructuredEdtArtifactGuardTest,WorkspaceCopyTransformToolTest,WorkspacePathContainmentTest \
  -Dsurefire.failIfNoSpecifiedTests=false package
docker volume rm "$MAVEN_VOLUME"
trap - EXIT
```

Result: 354 discovered, 354 executed, 0 skipped, 0 failures, 0 errors.
