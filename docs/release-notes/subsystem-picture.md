# Картинка подсистемы

`update_metadata` поддерживает назначение уже существующей общей картинки подсистеме:

```json
{"target_fqn":"Subsystem.Tools","changes":{"set":{"picture":"CommonPicture.ToolsIcon"}}}
```

Как для других изменений метаданных, обязательны `project` и одноразовый `validation_token`,
полученный через `edt_validate_request` для этого запроса.

При первом назначении создаётся вложенный `PictureRef`; повторное назначение заменяет его ссылку.
`changes: {"unset": ["picture"]}` снимает картинку, сохраняя сам объект `CommonPicture` и его файл.
Отсутствующая картинка и ссылка на метаданные другого вида отклоняются до изменения значения.
Поддержка ограничена свойством `Subsystem.picture`; общий запрет произвольной записи containment-ссылок сохраняется.

`edt_metadata_details` раскрывает вложенный `PictureRef` и показывает поле `picture` с FQN выбранной картинки.
Импорт бинарного содержимого общей картинки эта возможность не добавляет.
