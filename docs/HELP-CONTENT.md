# Встроенная справка метаданных

Для объекта, у которого модель EDT поддерживает справочную информацию,
`update_metadata` принимает отдельный запрос `set.help`:

```json
{
  "project": "ExampleProject",
  "target_fqn": "Catalog.Example",
  "changes": {
    "set": {
      "help": {
        "ru": "<html><head><meta charset=\"utf-8\"></head><body><h1>Справка</h1><p>Назначение и порядок работы.</p></body></html>",
        "en": "<html><body><h1>Help</h1><p>Purpose and usage.</p></body></html>"
      }
    }
  },
  "validation_token": "token-from-edt-validate-request"
}
```

Сначала выполнить `edt_validate_request` для этого же проекта, операции
`update_metadata` и полного payload без токена. Затем передать одноразовый токен
в `update_metadata`. Общая проверка запроса не заменяет проверку применимости
к выбранному объекту.

Переданные языки создаются или перезаписываются. Остальные языки и другие
свойства объекта сохраняются. Объединять `set.help` с другими `set`, `unset` или
дочерними операциями нельзя: такой запрос отклоняется до записи. Для обычных
изменений метаданных прежний маршрут сохраняется. Это API добавления и обновления
страниц; удаление справки в его контракт не входит.

Ключ языка состоит из двух или трех латинских букв, при необходимости с суффиксом
через дефис или подчеркивание. Регистр нормализуется. Пути, повторы языков,
пустой HTML и NUL отклоняются. Содержимое HTML передается как UTF-8 и не
переформатируется.

Метаданные `Help` и `HelpPage` создаются через BM и штатный `MdHelpUtil`.
Путь HTML определяется файловой службой EDT по странице модели. Произвольный
файловый путь пользователь не передает. При сбое транзакции восстанавливаются
прежние байты существующих страниц и удаляются только страницы, созданные
этим запросом. Ошибка восстановления сохраняется в диагностике.

После операции необходимо независимо прочитать метаданные (`Help.pages` с
кодами языков) и содержимое созданного файла, обычно `Help/ru.html` рядом с
владельцем. Сам инструмент также перечитывает HTML после экспорта и отклоняет
расхождение. Для приемки нового окружения дополнительно проверить платформенный
экспорт и доступность справки в клиенте.

`includeHelpInContents` этот запрос не меняет. Если требуется включение объекта
в оглавление справки, свойство задается отдельной обычной мутацией метаданных.
