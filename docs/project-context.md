# Контекст расширений EDT

`edt_project_context` использует публичный API установленного EDT Extension Tweaks
(`ru.xelgo.edt.contextlinks.ui`). Плагин не входит в поставку CodePilot и не является
обязательной зависимостью: при его отсутствии инструмент возвращает явный отказ.

Чтение: `project_name`, `action: "inspect"`. Результат содержит сохраненную настройку
Eclipse и действующий список плагина; их несовпадение видно отдельно.

Настройка: `action: "set"`, полный `context_projects`, сначала `dry_run: true`.
После проверки — `dry_run: false`, при необходимости `clean_build: true`.
Пустой массив явно снимает все связи; отсутствие массива ничего не очищает.
Все проекты должны существовать и быть открыты. Повторы, ссылка на себя и неизвестные
проекты отклоняются до записи. Изменение идет через API плагина, проверяется чтением
сохраненного свойства и действующего списка; файл `.project` не переписывается.

Пересборка выполняется только для указанного проекта. Ошибка сборки сообщается
отдельно: уже подтвержденная настройка остается сохраненной. Завершение команды сборки
не означает отсутствие диагностик — их проверять через `get_diagnostics`, а выполнение
BSL отдельно проверять на платформе 1С. Настройка контекста не меняет состав расширений
в информационной базе и не назначает тестовому проекту новую родительскую конфигурацию.
